# Next.js Frontend Scaffold

Lightweight Next.js App Router scaffold for the PQC migration dashboard.

## Run

1. Install dependencies at repo root (when package config is added):
   - `npm install`
2. Start dev server:
   - `npm run dev`
3. Build production bundle:
   - `npm run build`
4. Start production server:
   - `npm run start`

## Notes

- Source lives under `src/web`.
- Dashboard includes placeholders for inventory, HNDL heatmap, risk matrix, and proof panel.
- Styling is tokenized via CSS variables in `app/globals.css`.
